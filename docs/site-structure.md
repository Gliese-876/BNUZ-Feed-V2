## 维护规则

1. 官方站点身份、名称和 pubUrl 只维护 `bnuzhSites.ts`；以最新官方 siteList 为依据删除退出清单的注册，访问失败本身不构成移除依据。
2. 列表路径和分页放在 `bnuzh/targets`；解析器引用同一份配置。静态介绍、导航壳、登录入口和当前空列表不加入日期消息源。用户指引目录等有意保留无日期的内容需在实现和本表说明。
3. 代表页探测只能确认代表页；每次变更后还需完整快照流程核验全部当前目标。HTTP 错误、网络失败、DOM 变更和合法空列表应分别记录。
4. 发布日期只读取对应条目的发布日期字段，不把活动日程、报名截止日期或标题内日期当作发布时间；未提供发布日期时保持为空。禁止用当前年份、抓取时间或封面上传时间补造文章日期；保留附件与经过验证的站外真实文章 URL，过滤导航、占位及非 HTTP(S) 链接。
5. 运行 `npm run check:sources`、`npm run check:sources -- --probe`、`npx vitest run packages/source-registry`、`npm run snapshot`；同步更新本表与架构文档中的覆盖数字。
