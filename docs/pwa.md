# PWA 与离线阅读

生产构建生成 `manifest.webmanifest`、`sw.js` 和 Workbox 运行文件，随 GitHub Pages artifact 一同发布。清单的应用身份、启动地址与作用域使用 Vite 的 base，支持根路径和 `/BNUZ-Feed-V2/` 项目路径。图标使用列表与红色方块构成的图形，包含 192、512 像素图标及 Apple touch icon，中心图形位于 maskable 安全区域。

浏览器提供安装能力时，首页更新时间旁显示“安装应用”，点击后交由浏览器显示原生安装界面。没有原生安装事件的浏览器可使用其菜单添加到主屏幕。页面支持与安装条件见 [MDN](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)。

页面、脚本、样式和图标使用预缓存；体积较大的数据 JSON 不参与预缓存。信息快照使用 NetworkFirst，网络三秒内没有响应时优先返回现有副本，离线时使用最近副本。运行缓存最多保留两个数据 URL，按 base 隔离；IndexedDB 继续保存已解析的信息和原更新时间。首次联网载入并完成页面资源缓存后才能离线使用。原文页面和官方全站检索仍需要网络。

新 service worker 保持等待状态，首页出现“更新应用”后，由读者点击激活并刷新。首次安装不触发刷新。窗口重新获得焦点时，最多每小时检查一次页面版本；定时数据刷新不改变静态预缓存内容，也不会反复提示更新应用。开发服务器不注册 worker，使用 `npm run build` 后的 preview 验证。

内容自动同步默认开启：应用在前台且联网时，每 15 分钟读取已发布的快照；恢复联网会立即同步，回到前台时检查是否已到更新间隔。后台和离线时暂停计时，请求进行中不会叠加自动请求。手动更新会重新计算下次同步时间。搜索、栏目选择和已加载列表保留；旧离线/CDN 快照不会覆盖较新的内容。设置 `VITE_AUTO_REFRESH=false` 可关闭自动内容同步。关闭应用后不运行页面定时器。

验证应包括：清单解析与图标尺寸、根路径和项目路径下的 worker 作用域、离线重新导航、离线搜索与栏目切换、联网恢复和新版本等待。安装提示与更新按钮具有回归测试；浏览器的原生安装界面由浏览器负责。

2026-10-12 实测：根路径与 `/BNUZ-Feed-V2/` 均成功激活。停止隔离预览服务并断网后，重新打开仍可显示 2,324 条学生精选，切换全部信息可读 11,415 条，搜索“奖学金”得到 76 条；保持原数据时间。恢复联网后模拟新 worker，更新按钮出现，点击后激活并刷新，内容数量保持一致。320px 视口没有横向溢出。完整回归 395 项通过。

自动同步补充验证：恢复联网后，隔离数据自动从第一版变为第二版，搜索词、全部信息范围与输入焦点保留，页面 `performance.timeOrigin` 不变。随后服务端返回旧版本，运行缓存已收到旧响应，界面仍保持第二版。定时、暂停、请求合并、阅读窗口和旧数据保护具有回归测试，完整测试共 404 项通过。
