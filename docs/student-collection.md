# 学生精选

默认展示以在校本科生和研究生的日常需要为中心：学习事务、奖助通知、校园招聘活动、讲座、国际交流及生活安全服务。当前预设覆盖 16 个来源、73 个栏目；在 2026-10-12 的快照中显示 2,324 条去重内容，命中 2,465 条原始记录。

## 选择原则

- 教务：选课、考试、校历、毕业论文、实习实践、竞赛及学生交流机会。
- 学工与书院：奖助、宿舍事务、活动预告、心理与职业支持。
- 就业：宣讲会、双选会、就业活动及求职服务；大量单独岗位帖留在全部信息中。
- 校园生活：图书馆资源与培训、医保、餐饮、校园交通、网络服务及安全提醒。
- 全校与国际机会：主站通知和学术活动、国际办学生交流与全球视野活动。

泛行政科研动态和整站书院新闻不默认纳入。精选按原有时间顺序展示，保留原始来源与链接。跨站合并条目会标注实际命中当前筛选范围的来源及栏目。

## 界面与偏好

“学生精选”为首次使用的默认范围。“全部信息”打开完整已接入目录；手动勾选栏目进入“我的关注”。筛选面板和空结果中的恢复按钮会回到学生精选。

偏好保存为 `bnuz-feed:selection:v2`：预设只保存模式，自定义保存栏目键。迁移 v1 时识别当前目录全选及已知的 `dd4015b` 历史默认（44 个站点、459 个栏目），即使目录已经扩展也能进入精选；其他自定义、未知历史状态和空选择继续保留。历史默认以精确集合指纹识别，原始样本只用于回归测试。读写存储失败时仍可正常浏览与切换。

## 维护

规则位于 [studentCollection.ts](../apps/web/src/studentCollection.ts)，按官方来源 ID 和精确栏目名选择，避免因站点更名误选，也不会自动加入新的行政栏目。新增或移除规则后执行学生精选、选择状态和 App 测试；规则测试会检查各栏目仍存在。

未来出现新的学生服务栏目时，应根据实际内容决定是否加入。来源被移除时失效规则不会选中其他来源，但需要同步清理配置与文档。
